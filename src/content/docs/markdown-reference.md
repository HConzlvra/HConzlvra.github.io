常用的 Markdown 语法一览，写文档的时候备查。

## 标题

`#` 到 `######` 依次是一到六级标题。

## 行内格式

| 写法 | 效果 |
| --- | --- |
| `**加粗**` | **加粗** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |

行内代码用一对反引号包起来，比如 `` `code` ``。

## 列表

- 无序列表：`- 项目` 或 `* 项目`
1. 有序列表：`1. 项目`
- 嵌套：缩进两个空格
